# Security Policy

## Supported versions
Security fixes are provided for the latest version on the default branch. No release series is currently designated as supported.

## Reporting a vulnerability
Do not open a public issue for a suspected vulnerability. Use GitHub private vulnerability reporting if enabled, or contact the repository owner privately through their GitHub profile.

Include a description, impact, safe reproduction steps, and a suggested mitigation if known. Do not include credentials, tokens, personal data, or customer information.
